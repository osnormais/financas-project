# financas-project


## Sobre Projeto

O Finanças é um projeto de aplicativo para ajudar pessoas a organizar e acompanhar suas finanças pessoais. A proposta é criar uma experiência clara e prática, desenvolvida a partir das necessidades dos usuários.


## Sobre este repositório

Aqui ficam os artefatos que apoiam a concepção do app, como telas, fluxos de navegação e desenhos arquiteturais.

Os cards, o backlog e o planejamento das sprints ficam no board do GitHub. Este repositório é dedicado aos materiais que ajudam a visualizar e orientar o produto.
